Selected projects

The Economic Report Influence Graph

July 2026 – present

TypeScript · React · Three.js · no backend · github.com/DriftingSplash9/Reports-Clustering

  • A browser-based 3D map of where official numbers come from: which published statistical report is calculated from which other, across 130+ countries and every tier from national to municipal.
  • Built on one rule — no document, no edge. A dependency is drawn only where a published source says so in quotable words, and every edge carries an A/B/C grade for how well its citation supports it. Holding that standard across eighty-plus research sessions is the hard part, so the repository carries a fixed extraction protocol and a validator that refuses to pass on a dangling reference.
